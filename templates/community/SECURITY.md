# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

If this repository is hosted on GitHub, report it through the private
Security Advisories page instead: `https://github.com/OWNER/REPO/security/advisories/new`
(replace `OWNER/REPO` with this repository's own path). Only maintainers with
access to the repository's security tab can see a report filed that way.
